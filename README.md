# Git/Hub Level Two Side Quest

## What is a side quest?
- A side quest is a small task or project designed to be completed within a specific time frame. It promotes learning through hands-on coding experience. This side quest's purpose is to help you practice data preparation and visualization using Python and the **Iris dataset**. If you aren’t familiar with these concepts, our Level One walkthrough is a great place to start.

## Difficulty = ★☆☆

## What you will do:
- Git Basics: Manage a local repository by initializing, committing, and exploring changes.
- Remote Repository Basics: Connect your local repository to a remote GitHub repository and push changes.

## How you will do it:
- In this challenge, you will demonstrate fundamental Git skills by managing a local repository, committing changes, and connecting to a remote repository. Follow the instructions found in the repository to complete this level.

## Duration:
- A few hours
